OpenRouteService-API-Key

Damit Routen berechnet werden können, brauchst du einen kostenlosen Schlüssel:

1. Gehe auf openrouteservice.org → Sign up
2. Bestätige deine E-Mail und logge dich ein
3. Unter „Dashboard → Tokens" einen Token erstellen
4. Den Token hier einfügen.

Der Schlüssel wird nur lokal auf diesem Gerät gespeichert.
